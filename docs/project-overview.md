# SustainStyle — Project Overview

## Project summary

SustainStyle is a mobile app prototype intended to promote sustainable fashion choices through product scanning, EcoScores, recommendations, and reward-based engagement.

## Problem statement

The project presentation identifies fast fashion impacts including carbon emissions, water pollution, microfiber release, and textile waste. It also highlights overconsumption driven by low prices, trends, and social-media influence. The concept responds to the need for clearer eco-impact information and stronger motivation for consumers.

## Goal

Promote sustainable fashion choices using real-time eco-impact scores, AI-driven recommendations, and reward-based engagement. This is the stated goal of the concept; the presentation does not document a deployed scoring service or a live AI system.

## Main user flow

1. A user chooses a product scanning method: barcode, QR code, or style number.
2. The prototype displays an EcoScore for the scanned item.
3. If the score is low, the concept offers more sustainable alternatives.
4. Users earn GreenPoints for sustainable actions and take part in weekly challenges.
5. Progress indicators and milestones show the user's reward progress.

## GreenPoints milestones

| Points | Indicator described in the presentation |
|---:|---|
| 50 | Red |
| 250 | Orange |
| 500 | Green |

Example reward: reaching 250 GreenPoints unlocks a hemp shirt valued at ₹700.

## Prototype tools and scope

The interface was designed in Figma. The presentation describes clickable navigation, simulated scanning, and an interactive GreenPoints dashboard. The current project is a design prototype, not a complete production app.
